One line. One Monday. One star.

`main.ts` writes a single one-line review of Monday (121 characters) to
`$MAKEFUN_OUTPUT_DIR/entry.txt`:

> Monday, one star: my alarm hit snooze on me, my inbox held a meeting about meetings, and my coffee needed a coffee first.

Run it with Node 22+:

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

"Monday, Reviewed in One Line" (`u-zeroxfive-monday-reviewed-in-one-line-e55de3c1`).
